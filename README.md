# Tim Core
>Thanks for taking an interest in Tim Core! It started out as a way for me to get my common code between my 20+ Cobblemon sidemods organized and in one spot so I wasn't updating (or forgetting to update) the same chunk of code every update across every mod.
>It snowballed into a Cobblemon sidemod of its own, my "layer over Cobblemon," fixing bugs in the Cobblemon code, adding options I thought should be present in Cobblemon itself, and even adding some lower level features I thought should be present in Cobblemon itself.
>Now, it's grown into a multipurpose Minecraft mod-building API kit with built-in features for Cobblemon as a secondary layer. If you want to dive into making mods - whether for Cobblemon or just for Minecraft - I hope it makes your life easier. It's smart enough to turn features on and off depending on whether or not other mods are present, and lets you build features in such a way that they can be disabled if the end user doesn't want that part of your larger mod in their game.
